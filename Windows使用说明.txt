========================================================
  有话 · 抖音文案工作台（Windows 绿色免安装版）使用说明
========================================================

【一、如何启动】
1. 请先将压缩包完整解压到任意文件夹（不要直接在压缩包内双击运行）。
2. 双击文件夹中的【启动文案工作台.exe】（或【启动文案工作台.bat】）。
3. 程序会自动启动本地服务，并自动在默认浏览器中打开：
   http://127.0.0.1:3210
4. 使用期间请保留弹出的黑色控制台窗口，关闭该窗口即可停止服务。

【二、如何创建桌面快捷方式】
- 右键点击文件夹内的【启动文案工作台.exe】 -> 选择“发送到” -> “桌面快捷方式”，
  之后即可直接在桌面双击图标一键启动。

【三、免安装说明】
- 本程序已在 runtime 文件夹中内置了官方 Windows 64位 Node.js 22 运行环境，
  电脑无需额外安装任何软件即可直接运行。
- 如果 Windows 弹出“Windows 已保护你的电脑（SmartScreen）”提示：
  点击“更多信息” -> 点击“仍要运行”即可（或者直接双击旁边的【启动文案工作台.bat】）。
