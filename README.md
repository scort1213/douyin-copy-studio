# 有话 · 抖音文案工作台

本地运行的中文文案网站。默认使用 AI Hub Mix 的 `gemini-4-argon`，可修改模型名称。

## 启动

需要 Node.js 22 或更新版本（Windows 绿色打包版已在 `runtime/` 内置 Node.js 22，免安装），无需安装 npm 依赖。

- **Windows**：双击 **启动文案工作台.exe**（或 **启动文案工作台.bat**）。保留打开的控制台窗口，浏览器会自动打开网站。按 `Ctrl+C` 或关闭窗口停止服务。
- **macOS**：双击 **启动文案工作台.command**。保留打开的终端窗口，浏览器会自动打开网站。按 `Ctrl+C` 停止服务。

也可在此目录运行：

```sh
npm start
```

打开 <http://127.0.0.1:3210>。请始终使用这个地址，浏览器保存的配置与地址绑定。重复双击启动文件会打开已有服务。

## 使用

1. 粘贴 AI Hub Mix API Key。网站会自动保存在此浏览器。点击“清除”可删除。
2. 点击“填入单向历范例”，或自行填写产品、卖点和受众。
3. 选择思考程度（低／中／高），设置篇数、字数和表达特点，点击“生成文案”。思考程度自动保存，默认低档，仅适用于 `gemini-4-argon`。切换档位不会自动调用 API。
4. 检查文案，复制单篇或全部结果。点击“再写一组”可按当前表单重新生成。

字数统计包含标点，不计空白。135 字的提示范围为 120～150 字；其他目标字数也采用上下 15 字的范围。超出范围会显示提示，不会自动发起付费重写。每组结果只保留在当前页面，刷新后清空。

API Key 保存在本机浏览器的 localStorage 中，**未加密**。只在你信任的本机浏览器中使用。Key 会经本地服务转发至 AI Hub Mix，不写入源码、服务器文件或日志。文案素材也会发送给 AI Hub Mix。

每次生成只发送一次上游请求。取消会中断本地等待并尝试关闭上游连接，无法保证撤销上游已开始的计算或费用。服务等待上限为 180 秒，失败或取消均保留页面中的旧结果。

默认模型按选择的思考程度调用，输出预算为 32768 tokens，包含模型推理消耗，并非要求生成这么长的正文。高档可能耗时更长、费用更高，不保证文案更好；服务仍保留 180 秒等待上限。不自动切换模型或重试。其他模型禁用思考程度控件，使用最小兼容请求参数。

## 常见问题

- **Key 无效：** 检查 Key 是否完整、过期或已撤销。
- **余额或权限问题：** 检查 AI Hub Mix 账户余额、额度及模型权限。
- **模型不可用：** 从 AI Hub Mix 复制准确的模型 ID。
- **无法连接：** 确认终端仍在运行，并检查本机访问 AI Hub Mix 的网络。
- **端口被占用：** 先尝试打开上述网址。若不是本应用，停止占用 3210 的其他服务后启动。
